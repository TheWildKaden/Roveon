# Roveon

Roveon is an AI-powered development environment built around a focused, keyboard-first workspace.

## Current increment

This first slice is a frontend-only workspace shell with realistic sample project data. It includes a project explorer, file tabs, a code surface, terminal surface, preview toggle, and a conversational assistant interaction. Execution, authentication, persistence, Monaco integration, and secure agent tooling are intentionally not represented as complete features yet.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
